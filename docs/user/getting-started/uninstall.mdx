If you wish to remove Vespertine from your system, you can uninstall the `vespertine` or `vespertine-git` package using your distribution's package manager.

### Manual Installation

If you installed manually using `just install release`, remove the files installed under your prefix:

```bash
rm ~/.local/bin/vespertine
rm -rf ~/.local/libexec/vespertine
rm -rf ~/.local/share/vespertine
```

## Cleaning Up

After removing the package, you may want to remove the configuration and cache files.

### Configuration and Cache

Vespertine stores its configuration and cache in the standard XDG directories. To remove them:

```bash
rm -rf ~/.local/state/vespertine
rm -rf ~/.cache/vespertine
```

### Generated Templates

If you enabled any templates in the **Color Scheme** settings, you will need to manually delete the generated files.

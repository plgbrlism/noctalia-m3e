Emacs can be themed using the Vespertine color scheme through the built-in theme system.

## Setup

1. **Enable Emacs theming in Vespertine:**

- Open **Settings → Color Scheme → Templates → Programs**
- Toggle on **Emacs**

2. **Add the theme to your Emacs configuration:** Add the following line to your Emacs configuration file (typically `~/.emacs.d/config.el`, or `~/.config/doom/config.el`):

   ```elisp
   (load-theme 'vespertine t)
   ```

   The `t` argument enables the theme immediately and disables any previously active themes.

:::note
If you get an error saying `vespertine-theme` can't be found, you may need to add the themes directory to your load path before loading the theme. The exact path may vary depending on your Emacs configuration:

```elisp
(add-to-list 'custom-theme-load-path "~/.config/emacs/themes/")
(load-theme 'vespertine t)
```
:::

3. **Reload your configuration:**

- Restart Emacs, or
- Evaluate the expression: `M-x eval-buffer` or `C-x C-e` after the line

## Configuration Example

Here's a complete example of how to add it to your `config.el`:

```elisp
;; Load Vespertine theme
(load-theme 'vespertine t)
```

You can also add it conditionally or after other configurations:

```elisp
;; Load Vespertine theme after startup
(add-hook 'after-init-hook (lambda () (load-theme 'vespertine t)))
```

## Troubleshooting

- **Theme not found:** Ensure that Emacs theming is enabled in Vespertine settings and that the theme files are being generated correctly. If the files exist but aren't found, add `(add-to-list 'custom-theme-load-path "~/.config/emacs/themes/")` before `(load-theme 'vespertine t)`.
- **Theme not applying:** Make sure you've added `(load-theme 'vespertine t)` to your Emacs configuration file
- **Colors not updating:** Restart Emacs or reload your configuration after changing color schemes in Vespertine
- **Theme conflicts:** The `t` argument in `load-theme` disables other themes. If you want to keep other themes, you may need to adjust your configuration

## Additional Notes

The Vespertine theme for Emacs integrates with Vespertine's color scheme system. When you change color schemes in Vespertine, the Emacs theme will be regenerated to match. You'll need to reload the theme in Emacs to see the changes:

```elisp
(load-theme 'vespertine t)
```

Or use `M-x load-theme` and select `vespertine` from the list.

Add the following settings to your Hyprland Lua configuration file (usually found at `~/.config/hypr/hyprland.lua`).

## Autostart Vespertine

Add this to your `hyprland.start` event hook:

```lua
hl.on("hyprland.start", function()
  hl.exec_cmd("vespertine")
end)
```

## Compositor Settings

Add the following to your existing `hl.config({})` block. These settings are for general window appearance and functionality.

```lua
hl.config({
  general = {
    gaps_in = 5,
    gaps_out = 10,
  },

  decoration = {
    rounding = 20,
    rounding_power = 2,

    shadow = {
      enabled = true,
      range = 4,
      render_power = 3,
      color = 0xee1a1a1a,
    },

    blur = {
      enabled = true,
      xray = true,
      size = 3,
      passes = 2,
      vibrancy = 0.1696,
    },
  },
})
```

## Persistent Workspaces

For the best workspace indicator behavior, make your regular Hyprland workspaces persistent. This keeps empty workspaces visible in Vespertine instead of only showing workspaces that currently contain windows.

Update the monitor name and workspace list to match your setup. You can find more syntax and examples in the official [Workspace Rules](https://wiki.hypr.land/Configuring/Basics/Workspace-Rules/) documentation.

```lua
hl.workspace_rule({ workspace = "1", monitor = "DP-1", persistent = true, default_name = "web" })
hl.workspace_rule({ workspace = "2", monitor = "DP-1", persistent = true, default_name = "code" })
hl.workspace_rule({ workspace = "3", monitor = "DP-1", persistent = true, default_name = "chat" })
hl.workspace_rule({ workspace = "4", monitor = "DP-1", persistent = true, default_name = "game" })
hl.workspace_rule({ workspace = "5", monitor = "DP-1", persistent = true, default_name = "design" })
```

## IPC Keybinds

Add these binds to your `hyprland.lua`:

```lua
local mainMod = "SUPER"
local ipc = "vespertine msg "

-- Core binds
hl.bind(mainMod .. "+Space", hl.dsp.exec_cmd(ipc .. "panel-toggle launcher"))
hl.bind(mainMod .. "+S", hl.dsp.exec_cmd(ipc .. "panel-toggle control-center"))
hl.bind(mainMod .. "+comma", hl.dsp.exec_cmd(ipc .. "settings-toggle"))
hl.bind("ALT + Tab", hl.dsp.exec_cmd(ipc .. "window-switcher hold"))
hl.bind("ALT + SHIFT + Tab", hl.dsp.exec_cmd(ipc .. "window-switcher hold reverse"))

-- Media keys
hl.bind("XF86AudioRaiseVolume", hl.dsp.exec_cmd(ipc .. "volume-up"))
hl.bind("XF86AudioLowerVolume", hl.dsp.exec_cmd(ipc .. "volume-down"))
hl.bind("XF86AudioMute", hl.dsp.exec_cmd(ipc .. "volume-mute"))
hl.bind("XF86MonBrightnessUp", hl.dsp.exec_cmd(ipc .. "brightness-up"))
hl.bind("XF86MonBrightnessDown", hl.dsp.exec_cmd(ipc .. "brightness-down"))

-- Vespertine Settings
hl.window_rule({
    match = { class = "dev.vespertine.Vespertine" },
    float = true,
    size = "monitor_w*0.5625 monitor_h*0.85",
})
```

## Layer Animations

Disable Hyprland's built-in layer animations for Vespertine. Vespertine animates its own surfaces; Hyprland's `layersIn`/`layersOut` animations run on top of them and cause visual glitches, such as a panel tearing when it is reopened while still closing. Add this rule even if you do not use blur.

```lua
hl.layer_rule({
  name = "vespertine-no-anim",
  match = {
    namespace = "^vespertine-(bar-.+|notification|dock|panel|attached-panel|osd|window-switcher)$",
  },
  no_anim = true,
})
```

## Blur

Enable blur for Vespertine's bar, panels, dock, and notifications.

<ImageLightbox src={blur1} alt="Blurred Vespertine surfaces" />

```lua
hl.layer_rule({
  name = "vespertine-blur",
  match = {
    namespace = "^vespertine-(bar-.+|notification|dock|panel|attached-panel|osd|window-switcher)$",
  },
  ignore_alpha = 0.5,
  blur = true,
  blur_popups = true,
})
```

## Permissions

If you use Hyprland's [permission system](https://wiki.hypr.land/configuring/core/advanced-configuration/permissions/) (`ecosystem.enforce_permissions = true`), allow Vespertine to capture the screen and to connect its virtual keyboard. Without these rules, Hyprland asks for permission or denies access, depending on your other rules.

- `screencopy` is used for screenshots and lock screen desktop capture.
- `keyboard` is used for clipboard and launcher auto-paste. Hyprland names Vespertine's virtual keyboard `hl-virtual-keyboard-vespertine`.

```lua
hl.config({
  ecosystem = {
    enforce_permissions = true,
  },
})

hl.permission("^/usr/bin/vespertine$", "screencopy", "allow")
hl.permission("^hl-virtual-keyboard-vespertine$", "keyboard", "allow")
```

If Vespertine is installed somewhere else, for example `/usr/local/bin/vespertine`, change the binary path to match. Run `readlink -f "$(command -v vespertine)"` to find the path. If you have a catch-all `keyboard` rule such as `hl.permission(".*", "keyboard", "deny")`, keep it after the Vespertine rule.

Hyprland does not reload permission rules on config reload. Restart Hyprland after you change them.
